# יומן כיס – מימון

אפליקציית PWA ללימוד ושינון נוסחאות מימון, יחסים פיננסיים ומושגים. מתקינים אותה למסך הבית, והיא עובדת במלואה בלי אינטרנט.

- **נוסחאות** – 71 נוסחאות ב-10 נושאים, עם הסבר משתנים, פרשנות, דוגמה פתורה, טעויות נפוצות וטיפ למבחן.
- **מחשבון** – מחשבון לכל נוסחה, עם תוצאה בזמן אמת, חיווי צבע ופתרון שלב אחרי שלב.
- **לזכור** – נוסחאות ומושגים מסומנים, עם פתק אישי לכל אחד.
- **מילון** – כ-200 מושגים באנגלית ובעברית, עם קפיצה לפי אות.

## פיתוח

```bash
npm install
npm run dev      # שרת פיתוח
npm test         # בדיקות: כל מחשבון מול הדוגמה שלו, מיון המילון וקישורים
npm run build    # בנייה ל-dist
```

## הוספת תוכן

- **נוסחה:** מוסיפים אובייקט ל-`src/data/formulas.ts`. למחשבון מוסיפים מחשבון באותו `id` ב-`src/lib/calculators.ts`. ערכי `example.values` הם גם ערכי ברירת המחדל במחשבון, ו-`example.result` נבדק בטסטים.
- **מושג:** מוסיפים שורה ל-`src/data/glossary.ts`. המילון ממוין אוטומטית.

כל נתוני המשתמש (מסומנים, הערות, "נלמד", סדר, היסטוריית מחשבון) נשמרים ב-localStorage במכשיר.
