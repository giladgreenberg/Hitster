# 🎵 היטסטר – משחק מוזיקה עם ספוטיפיי

משחק מסיבות על מכשיר אחד, בהשראת "היטסטר", אבל בלי קלפים. בכל תור מתנגן שיר אקראי מספוטיפיי, והשחקנים צריכים למקם אותו בציר הזמן שלהם לפי שנת היציאה. מי שמגיע ראשון ל-10 שירים בציר מנצח.

- 2–8 שחקנים, מעבירים את הטלפון מיד ליד. אפשר לשחק גם לבד.
- שירים מהפלייליסטים שלכם, או אקראיים מספוטיפיי לפי טווח שנים וז'אנרים.
- **השנה המקורית:** האפליקציה מחפשת ב-[MusicBrainz](https://musicbrainz.org) את תאריך היציאה המוקדם ביותר של ההקלטה. כך שנה של רימאסטר או אוסף לא מבלבלת.
- אסימונים לפי החוקים המקוריים: דילוג, אתגר ("היטסטר!") וקניית שיר.
- עברית מלאה, מותאם לנייד, ואפשר להוסיף למסך הבית (PWA).

---

## 📜 חוקי המשחק

1. בתחילת המשחק כל שחקן מקבל שיר פתיחה אחד, גלוי עם השם, האמן והשנה. זה הבסיס של ציר הזמן שלו.
2. בכל תור מתנגן שיר. השם, האמן והשנה מוסתרים.
3. השחקן שבתור לוחץ על **+** במקום שבו לדעתו השיר נכנס: לפני השיר הראשון, בין שני שירים, או אחרי האחרון.
4. **חשיפה:** אם השנה נמצאת בין השכנים, השיר נכנס לציר. שנה זהה לשכן נחשבת נכונה. אחרת, השיר נזרק.
5. **מנצח** מי שמגיע ראשון ליעד. ברירת המחדל היא 10 שירים, ואפשר לשנות אותה בהגדרות.

### 🪙 אסימונים (אפשר לכבות בהגדרות)

| | |
|---|---|
| התחלה | כל שחקן מתחיל עם 2 אסימונים, ואפשר להחזיק עד 5 |
| ניחוש נכון של שם השיר והאמן | ‎+1 (השחקנים שופטים: "צדק" או "טעה") |
| ⏭ דילוג על שיר | 1 |
| ⚔️ אתגר ("היטסטר!") | 1 |
| 🛒 קניית שיר (נכנס לציר אוטומטית) | 3 |

**אתגר:** השחקן שבתור ממקם את השיר ולוחץ "סיימתי למקם". עכשיו שחקן אחר, אחד בלבד בכל תור, יכול לשים אסימון על מקום אחר באותו ציר. אם השחקן שבתור טעה והמאתגר צדק, השיר עובר לציר של המאתגר. בכל מקרה אחר המאתגר מפסיד את האסימון.

**"השנה שגויה?"** קורה שהשנה בספוטיפיי או ב-MusicBrainz לא נכונה. הכפתור במסך החשיפה מבטל את התור בלי עונש, ואסימונים ששולמו חוזרים. השיר נכנס לרשימה שחורה, ואותו שחקן מקבל שיר אחר.

## ✅ מה צריך

- חשבון **Spotify Premium**. ספוטיפיי מאפשר השמעה דרך אפליקציות חיצוניות רק למנויי Premium.
- חשבון **GitHub** (חינם), שבו נמצא הקוד.
- חשבון **Vercel** (חינם), לפרסום האתר.

אין צורך להתקין שום דבר על המחשב, אלא אם רוצים להריץ את האתר מקומית (ראו בסוף).

---

## 1️⃣ יצירת אפליקציה בספוטיפיי

1. היכנסו ל-<https://developer.spotify.com/dashboard> עם חשבון ה-Premium, ואשרו את תנאי השימוש אם תתבקשו.
2. לחצו **Create app** ומלאו:
   - **App name:** `Hitster`
   - **App description:** `Private music guessing game`
   - **Website:** אפשר להשאיר ריק.
   - **Redirect URIs:** הקלידו `http://127.0.0.1:5173/callback` ולחצו **Add**. את כתובת האתר מוסיפים אחרי הפרסום, בשלב 3.
   - תחת **Which API/SDKs are you planning to use** סמנו **Web API** וגם **Web Playback SDK**.
3. סמנו את ההסכמה לתנאים ולחצו **Save**.
4. בדף האפליקציה לחצו **Settings** והעתיקו את ה-**Client ID**. את ה-Client Secret לא צריך.
5. **User Management:** הוסיפו את כתובת המייל של חשבון הספוטיפיי שלכם. אם עוד אנשים יתחברו מהמכשירים שלהם, הוסיפו גם אותם. במצב Development אפשר להוסיף עד 5 משתמשים.

> ספוטיפיי לא מקבל יותר `localhost`. לכן כתובת הפיתוח היא `127.0.0.1`.

---

## 2️⃣ פרסום ב-Vercel (חינם)

1. היכנסו ל-<https://vercel.com/signup>, בחרו **Hobby** ולחצו **Continue with GitHub**.
2. **Add New…** ← **Project** ← ליד ה-repository **Hitster** לחצו **Import**.
   - לא מופיע? לחצו **Adjust GitHub App Permissions** ותנו ל-Vercel גישה ל-repository.
3. אין מה לשנות בהגדרות, כי Vercel מזהה Vite לבד. לחצו **Deploy** וחכו כדקה.
4. ב-**Overview**, תחת **Domains**, תופיע הכתובת הקבועה, למשל `hitster-xyz.vercel.app`. העתיקו אותה.
   - **לא** את הכתובת הארוכה עם הרצף האקראי, כי היא משתנה בכל פרסום.

מעכשיו כל שינוי שנשמר ב-GitHub יתפרסם לבד תוך כדקה.

### (רשות) Client ID קבוע
בלי ההגדרה הזו, בכניסה הראשונה מכל מכשיר מדביקים את ה-Client ID במסך ההתחברות. כדי לחסוך את זה:
1. ב-Vercel: **Settings** ← **Environment Variables**.
2. הוסיפו משתנה בשם `VITE_SPOTIFY_CLIENT_ID`, עם ה-Client ID כערך.
3. **Deployments** ← על הפרסום האחרון: **⋯** ← **Redeploy**.

---

## 3️⃣ הוספת כתובת האתר לספוטיפיי

1. בדף האפליקציה בספוטיפיי: **Settings** ← **Edit**.
2. ב-**Redirect URIs** הוסיפו את הכתובת הקבועה, עם `https://` בהתחלה ו-`/callback` בסוף:
   ```
   https://hitster-xyz.vercel.app/callback
   ```
   הכתובת המדויקת מופיעה גם בתחתית מסך ההתחברות של המשחק, ואפשר להעתיק אותה משם.
3. לחצו **Add** ואז **Save**.

---

## 4️⃣ משחקים!

1. פתחו את האתר, הדביקו את ה-Client ID ולחצו **"התחברות עם ספוטיפיי"**.
2. במסך ההגדרות בחרו שחקנים, מקור שירים, יעד, ועל מה לנגן. אחר כך לחצו **"יאללה, מתחילים!"**.

### על מה לנגן?
- **במחשב:** "נגן כאן בדפדפן". הדפדפן עצמו מנגן, ושם השיר לא מוצג בשום מקום. מומלץ בכרום או אדג'.
- **בטלפון:** דפדפנים בטלפון לא יכולים לנגן ישירות, ולכן המשחק שולט באפליקציית ספוטיפיי:
  1. פתחו את אפליקציית ספוטיפיי, נגנו שיר לשנייה ועצרו.
  2. חזרו למשחק ובחרו את הטלפון מרשימת המכשירים.

  ⚠️ אפליקציית ספוטיפיי מציגה את שם השיר. הניחו את הטלפון עם המסך כלפי מטה, או השתמשו ברמקול.
- אפשר לבחור גם רמקול, טלוויזיה או כל מכשיר אחר שמופיע ברשימה.

### שירים בעברית
ספוטיפיי מחזיר תוכן רק מפלייליסטים שבבעלותכם. מצאתם פלייליסט ישראלי טוב? העתיקו אותו לחשבון שלכם:
1. פתחו אותו באפליקציה.
2. **⋯** ← **"הוספה לפלייליסט אחר"** ← **"פלייליסט חדש"**.

עכשיו הוא יופיע תחת "הפלייליסטים שלי".

### 📲 הוספה למסך הבית
- **אנדרואיד (כרום):** תפריט **⋮** ← **"הוספה למסך הבית"** או **"התקנת אפליקציה"**.
- **אייפון (ספארי):** כפתור השיתוף **⬆️** ← **"הוספה למסך הבית"**.

## 🛠 פתרון בעיות

| בעיה | פתרון |
|---|---|
| `redirect_uri: Not matching configuration` | הכתובת ב-Redirect URIs לא זהה בדיוק לכתובת האתר. העתיקו אותה מתחתית מסך ההתחברות, ולחצו **Save** בספוטיפיי. |
| שגיאה 403 בהתחברות | המייל של חשבון הספוטיפיי לא רשום ב-**User Management**. |
| הטלפון לא מופיע ברשימת המכשירים | פתחו את אפליקציית ספוטיפיי, נגנו שיר לשנייה, וחזרו למשחק. הרשימה מתרעננת לבד. |
| הטלפון מופיע אבל לא מנגן | השאירו את ספוטיפיי פתוחה על המסך. באפליקציה: **הגדרות** ← **מכשירים**, וודאו ש-**"Spotify Connect ברקע"** פועל. בהגדרות הטלפון בטלו חיסכון סוללה לספוטיפיי. |
| "הנגן בדפדפן דורש Premium" | השמעה דרך אפליקציות חיצוניות אפשרית רק עם Premium. |
| השנה של שיר לא נכונה | לחצו **"השנה שגויה?"** במסך החשיפה. |
| נגמרו השירים | בחרו עוד פלייליסטים, או הרחיבו את טווח השנים והז'אנרים. |

יש גם **"מסך בדיקות"**, בקישור בתחתית מסך ההגדרות. הוא מציג לכל שיר מאיפה הגיעה השנה, ומריץ "בדיקת טלפון" שמראה מה ספוטיפיי עונה על כל פקודת השמעה.

## ⚙️ איך זה עובד (למי שמתעניין)

- **React + Vite + TypeScript + Tailwind.** האתר רץ כולו בדפדפן, בלי שרת.
- **התחברות:** Authorization Code with PKCE, כך שאין צורך ב-client secret. הטוקן נשמר בדפדפן ומתרענן לבד.
- **השמעה:**
  - במחשב: Spotify Web Playback SDK.
  - בכל מכשיר אחר: Spotify Connect דרך `PUT /me/player/play`. יש כמה דרכי גיבוי למכשירים שמתעלמים מהפקודה, והמשחק זוכר איזו דרך עבדה בכל מכשיר.
- **השנה המקורית:**
  1. לוקחים את ה-ISRC של השיר (`external_ids.isrc`) ומחפשים אותו ב-MusicBrainz. בקשה אחת לשנייה לכל היותר, כמו שהם מבקשים.
  2. אם אין תוצאה, משתמשים בשנה מספוטיפיי. במקרה כזה מדלגים על שירים שבשם שלהם או של האלבום מופיע Remaster, Live, Greatest Hits, Best Of, Collection, Anniversary או Deluxe, ועל אלבומי אוסף.
  3. כל שנה שנמצאה נשמרת במטמון בדפדפן.
- **טעינה מוקדמת:** תמיד יש כמה שירים מוכנים ברקע.
- **שמירת המשחק:** נשמר בדפדפן, ורענון לא מוחק אותו.
- **מגבלות של ספוטיפיי במצב Development (2026):**
  - חיפוש מחזיר עד 10 תוצאות לבקשה.
  - אין שליפה של כמה שירים בבקשה אחת.
  - תוכן פלייליסטים זמין רק לפלייליסטים שבבעלותכם.
  - עד 5 משתמשים מורשים.

### מבנה התיקיות
```
src/
  spotify/    התחברות (PKCE) וקריאות API
  songs/      מקורות שירים, MusicBrainz, מטמון שנים, סינון, תור טעינה מוקדמת
  playback/   נגן בדפדפן (SDK), שליטה במכשירים (Connect)
  game/       חוקי המשחק + בדיקות אוטומטיות, שמירה
  components/ ציר זמן, כרטיס מתהפך, לוח ניקוד, בחירת מכשיר, כפתורי נגן
  screens/    התחברות, הגדרות, משחק, סיום, מסך בדיקות
```

### הרצה מקומית (למפתחים)
צריך [Node.js](https://nodejs.org) גרסה 20 ומעלה.
```bash
npm install
cp .env.example .env.local   # ומלאו את VITE_SPOTIFY_CLIENT_ID (או הדביקו אותו במסך ההתחברות)
npm run dev                  # http://127.0.0.1:5173
npm test                     # בדיקות אוטומטיות
npm run build                # בנייה לפרסום
```
